# ProdigyInfotech-Internship

## Task 1: Visualization for Distribution of Population
This project focuses on analyzing and visualizing population distribution using various data visualization techniques. The dataset includes demographic data such as age groups, gender, and geographical distribution. Different types of plots, including histograms, bar charts, and density plots, are used to represent the distribution effectively. The visualizations help in understanding population trends, urban-rural distribution, and demographic patterns. These insights can be useful for policy-making, urban planning, and resource allocation.

## Task 2: Data Cleaning and Exploratory Data Analysis (EDA)
This project involves cleaning and analyzing data to extract meaningful insights. Using datasets like Titanic survival data, various data preprocessing techniques are applied, such as handling missing values, encoding categorical variables, and removing redundant features. Exploratory Data Analysis (EDA) is performed using statistical summaries, visualizations, and correlation matrices to identify patterns and trends. Findings reveal key factors influencing outcomes, such as the impact of gender, passenger class, and age on survival rates.

## Task 3: Customer Purchase Prediction using Decision Tree Classifier
This project aims to predict whether a customer will purchase a product or service based on their demographic and behavioral data. Using the Bank Marketing dataset, the categorical data is encoded and a Decision Tree Classifier is built. The model is trained and tested using accuracy scores, classification reports, and feature importance analysis. The results show that factors like previous marketing interactions, duration of contact, and job type play a significant role in determining whether a customer will make a purchase.

## Task 4: Traffic Accident Analysis and Hotspot Visualization
This project analyzes traffic accident data to identify patterns related to road conditions, weather, and time of the day. The dataset is cleaned, and missing values are handled before performing exploratory data analysis (EDA). Visualizations like scatter plots, heatmaps, and bar charts highlight accident trends. Machine learning techniques, such as K-Nearest Neighbors (KNN) and oversampling methods like SMOTE, are used to predict accident severity. The study identifies key contributing factors to accidents, helping in urban planning, traffic management, and road safety improvements.
