# Task 2: Titanic Dataset - Data Cleaning & EDA

## Problem Statement - 
Perform data cleaning and exploratory data analysis (EDA) on a dataset of your choice, such as the Titanic dataset from Kaggle. Explore the relationships between variables and identify patterns and trends in the data.

## Overview -
This project involves data cleaning and exploratory data analysis (EDA) on the Titanic dataset from Kaggle. The goal is to explore relationships between variables, identify patterns, and extract meaningful insights from the data. Various visualization techniques and statistical methods are used to analyze survival trends.

## Dataset -
The dataset (titanic.csv) contains passenger details such as age, gender, class, fare, and survival status. The data is cleaned to handle missing values, convert categorical data, and remove irrelevant columns before conducting exploratory data analysis.

## Technologies Used
* Python
* Pandas (for data manipulation)
* Matplotlib & Seaborn (for visualization)
  
   
## The analysis will display data insights and visualizations such as:
    * Age & Fare distributions
    * Survival rates by gender, class, and embarkation point
    * Correlation heatmap of numerical features
    * Age vs. Fare scatter plot
    
## Key Findings & Insights
* Women had a higher survival rate than men.
* First-class passengers had better survival chances compared to lower classes.
* Passengers who embarked from Cherbourg had a higher survival rate.
* Young adults had lower survival rates, possibly due to evacuation priorities.
* Fare, gender, class, and embarkation location were strong indicators of survival chances.

## Conclusion
This project showcases how EDA and visualization can help in understanding trends and patterns in real-world data. By applying these techniques, we can gain valuable insights and improve decision-making in similar classification problems.
